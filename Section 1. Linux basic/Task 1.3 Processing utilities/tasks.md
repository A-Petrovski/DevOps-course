# Практические задания (Чекпоинты) — Task 1.3: Утилиты обработки текста и логов

## Резюме (Summary)
В рамках модуля **Task 1.3** отработаны базовые и продвинутые навыки работы с текстовыми данными и логами в среде Linux без использования интерактивных текстовых редакторов:
- **Потоки и перенаправления:** управление стандартным выводом (`stdout` / `1>`), подавление ошибок доступа (`2>/dev/null`) и построение конвейеров (`|`).
- **Анализ дискового пространства:** фильтрация столбцов вывода системных утилит и человекочитаемая сортировка размеров файлов и директорий.
- **Фильтрация и поиск по шаблонам:** применение базовых и расширенных регулярных выражений (`ERE`) в `grep`, `sed` и `awk`.
- **Потоковое редактирование:** безопасная замена значений в конфигурационных файлах на резервных копиях (`passwd.bak`) с использованием альтернативных разделителей.
- **Документирование работы:** сохранение истории выполненных команд в отдельный файл для воспроизводимости.

## 1. Вывод размеров разделов диска и фильтрация столбцов
```bash
df -hP | awk '{print $1, $5, $6}' | column -t > info.txt
```
- `-h` (`df`) — вывод размеров в человекочитаемом формате (K, M, G).
- `-P` (`df`) — вывод в формате POSIX (запрещает перенос длинных имен файловых систем на новую строку, сохраняя целостность столбцов).
- `awk '{print $1, $5, $6}'` — выборка 1-го (`Filesystem`), 5-го (`Use%`) и 6-го (`Mounted on`) столбцов с автоматическим схлопыванием пробелов.
- `-t` (`column`) — выравнивание вывода в ровную таблицу по ширине колонок.
- `>` — перенаправление стандартного вывода (`stdout`) в файл `info.txt` с перезаписью.

## 2. Поиск 10 самых больших файлов и папок в `/etc`
```bash
sudo du -ah /etc 2>/dev/null | sort -rh | head -n 10
```
- `-a` (`du`) — учет размеров не только директорий, но и каждого отдельного файла.
- `-h` (`du` / `sort`) — человекочитаемый формат размеров и корректное сравнение единиц измерения (КБ, МБ, ГБ) при сортировке.
- `2>/dev/null` — перенаправление потока ошибок (`stderr`, например `Permission denied`) в пустое устройство.
- `-r` (`sort`) — обратный порядок сортировки (от большего к меньшему).
- `-n 10` (`head`) — ограничение вывода первыми 10 строками.

*Альтернатива (строго только файлы, без директорий):*
```bash
sudo find /etc -type f -exec du -h {} + 2>/dev/null | sort -rh | head -n 10
```
- `-type f` (`find`) — фильтрация объектов только по типу «обычный файл».
- `-exec ... {} +` (`find`) — передача списка найденных файлов в утилиту `du` пакетами для ускорения выполнения.

## 3. Создание файла с заданным содержимым
```bash
cat << 'EOF' > data.txt
NDS/A
NSDA
ANS!D
NAD/A
EOF
```
- `<< 'EOF'` — конструкция `Here-Document` для многострочной записи в файл (одинарные кавычки вокруг `EOF` отключают интерпретацию спецсимволов вроде `!` и `$` оболочкой Bash).

## 4. Поиск строк `NDS/A` и `NAD/A` с помощью регулярных выражений

### Вариант с `sed`:
```bash
sed -nE '/^N(DS|AD)\/A$/p' data.txt
```
- `-n` (`sed`) — отключение автоматического вывода всех строк (печатаются только строки с явной командой `p`).
- `-E` (`sed` / `grep`) — включение расширенных регулярных выражений (`ERE`), чтобы использовать группировку `(...)` и оператор ИЛИ `|` без экранирования.
- `/^N(DS|AD)\/A$/p` — поиск строк, начинающихся с `N`, за которым идет `DS` или `AD`, экранированный слеш `\/` и `A` в конце строки (`$`).

### Вариант с `awk`:
```bash
awk '/^N(DS|AD)\/A$/' data.txt
```
- `/шаблон/` (`awk`) — действие по умолчанию при совпадении с регулярным выражением в `awk` — вывод всей строки целиком (`{print $0}`).

## 5. Вывод пронумерованных строк из `/etc/passwd` с оболочкой `/bin/bash`
```bash
grep '/bin/bash$' /etc/passwd | nl -s ". " > bash_users.txt
```
- `'/bin/bash$'` (`grep`) — якорь `$` гарантирует совпадение только в самом конце строки (в поле интерпретатора пользователя).
- `-s ". "` (`nl`) — задание разделителя (точка с пробелом) между номером строки и текстом.

*Альтернатива с сохранением оригинальных номеров строк из `/etc/passwd`:*
```bash
grep -n '/bin/bash$' /etc/passwd > bash_users_orig_lines.txt
```
- `-n` (`grep`) — вывод номера строки, который она занимает в исходном файле.

## 6. Безопасная замена `/bin/sh` на `/bin/bash` в копии `passwd.bak`
```bash
cp /etc/passwd ~/passwd.bak
sed -i 's|/bin/sh$|/bin/bash|' ~/passwd.bak
```
- `-i` (`sed`) — редактирование файла на месте (`--in-place`). При указании суффикса (`-i.orig`) дополнительно создается резервная копия перед изменением.
- `s|старое|новое|` — использование вертикальной черты `|` в качестве разделителя вместо слеша `/`, чтобы избежать конфликта со слешами внутри путей `/bin/sh` и `/bin/bash`.
- `$` — привязка к концу строки, чтобы не повредить уже существующие записи `/bin/bash`.

### Памятка для обсуждения с ментором (`/etc/passwd`):
- **Назначение файла:** хранит учетные записи всех локальных и системных пользователей (логин, UID, GID, описание, домашнюю директорию и оболочку входа в формате 7 полей через `:`).
- **Риски редактирования оригинала:**
  1. Синтаксическая ошибка или случайное удаление системного пользователя (например, `root`) заблокирует вход в систему и работу системных служб.
  2. Прямое редактирование через `sed -i` создает временный файл и переименовывает его поверх оригинала — это может сбить права доступа (`644`) или контекст безопасности (`SELinux`/`AppArmor`), из-за чего пользователи не смогут авторизоваться.
  3. Для безопасной правки в продакшене используется утилита `vipw` (ставит блокировку от одновременной записи и проверяет синтаксис) или `usermod -s`.

## 7. Сохранение истории использованных команд в отдельный файл
```bash
history | tail -n 20 > commands_history.txt
```
- `history` — вывод списка выполненных команд в текущей сессии терминала.
- `-n 20` (`tail`) — выборка последних 20 строк из потока вывода.
