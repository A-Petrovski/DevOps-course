## Введение
Большую часть времени ты будешь проводить, изучая различные конфиги, как уже скорее всего изучал `sshd_conf` в прошлом задании. Но желательно не только изучать, но и уметь работать с этими конфигами, а именно его содержимым — текстом/логами. В Linux есть куча встроенных утилит для обработки информации. Часть утилит просто выводит какую-либо информацию в консоль (как например `df`), другие же (`awk`, `sed`) позволяют обрабатывать полученную информацию, а также изменять текст не только на выходе, но и вставлять нужные значения в сам файл.

На самом деле работать с флагами команд иногда становится достаточно сложно, еще сложнее найти значение каждого флага. Например — команда `df -h`. Сама команда `df` показывает список всех файловых систем по именам устройств, сообщает их размер, занятое и свободное пространство и точки монтирования. А вот с поиском значения `-h` могут быть проблемы. Конечно можно воспользоваться командой `man df`. Поэтому можешь пользоваться сайтом `explainshell.com`.

Для манипуляций с файлами существует множество команд, мы разберем основные:

**`cut`** — используется для извлечения части строки из файла или ввода стандартного потока данных. Она может извлекать фрагменты данных по позициям символов или по позициям полей (разделенных разделителем). Например, можно использовать `cut` для извлечения только нужных колонок из таблицы или для извлечения только части имени файла из полного пути.

Например, у тебя есть файл `file.txt` со следующим содержимым:
```text
123,John,Doe,23
456,Jane,Smith,29
789,Bob,Johnson,45
```

Мы хотим извлечь из него только имена и фамилии, для этого используем следующую команду:
```bash
cut -d ',' -f 2,3 file.txt
```

На выходе получаем:
```text
John,Doe
Jane,Smith
Bob,Johnson
```

Возможно у тебя возникла мысль: вот я хочу взять вывод из одной команды и обработать его другой командой. Здесь мы и сталкиваемся с *input & output redirections*, а также *pipes*.

Обо всем поподробнее. Для того, чтобы перенаправить вывод из одной команды в другую используется символ `|` (*pipe*). Например:
```bash
cat log.txt | grep error
```
это выведет только те строки из файла `log.txt`, в которых есть слово `error`.

Другой пример:
```bash
ls -l /etc | cut -c1-10 | sort
```
берет вывод команды `ls -l`, затем отбирает первые 10 символов каждой строки с помощью команды `cut -c1-10`, а далее сортирует `sort` их и выводит на экран.

Но что, если мы хотим сохранить вывод в файл? Для этого используется символ `>>` (*output*).

Теперь команда:
```bash
ls -l /etc | cut -c1-10 | sort >> file.txt
```
сохранит все проведенные манипуляции ранее в файл `file.txt`, все достаточно просто.

Теперь поговорим про работу с самим содержимым файла. Как уже упоминалось ранее, мы будем использовать команды `awk` и `sed`. Для работы с ними нужно уметь писать *regular expressions*.

* **AWK** является языком программирования, который предназначен для обработки и анализа текстовых данных. Он обладает сильными возможностями для работы со строками, регулярными выражениями и математическими функциями. Например команда:
  ```bash
  ls -la | awk '{print $2}' >> file.txt
  ```
  берёт вывод `ls -la` и для каждой строки извлекает значение из второго столбца, после чего записывает его в файл `file.txt`.

* **SED** же является утилитой, которая предназначена для изменения текста в файле или в потоке данных. Он обладает сильными возможностями для работы с регулярными выражениями и используется для простых и быстрых изменений текста. Обычно используется для замены текста, вставки или удаления строк. Команда:
  ```bash
  sed -i 's/old_string/new_string/g' file.txt
  ```
  заменит `old_string` в `file.txt` на `new_string`.

## Чекпоинты
1. Вывести размеры разделов диска в отдельный файл. Отсортировать количество столбцов до трех, оставив только `Filesystem`, `Use%`, `Mounted on`.

3. Создать файл со следующим содержанием:
   ```text
   NDS/A
   NSDA
   ANS!D
   NAD/A
   ```
4. Вывести строки `NDS/A` и `NAD/A` из файла используя `awk` или `sed` (regexp).
5. Вывести пронумерованные строчки из `/etc/passwd`, в которых есть оболочка `/bin/bash`, и перенаправить вывод в файл.
6. Заменить все строчки с `/bin/sh` на `/bin/bash`. Проводить на заранее скопированном файле `passwd` (НЕ ОРИГИНАЛЕ, иначе будут проблемы (обсудить какие и для чего нужен этот файл с ментором)), просто скопируйте его и переименуйте в `passwd.bak`.
7. Используемые команды должны быть записаны в отдельный файлик.
