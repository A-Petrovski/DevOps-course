## Введение
В этой задаче ты сделаешь защищенное соединение, используя SSL/TLS. Возможно ты уже обращал внимание на замочек около поисковой страницы (это значит, что ты общаешься с веб-сервером по протоколу HTTPS), либо его отсутствие (HTTP) как например здесь. Что вообще под собой несет это защищенное соединение?

**SSL (Secure Sockets Layer)** — это криптографический протокол, который обеспечивает защищенную передачу данных между клиентом и сервером. Он шифрует информацию, передаваемую между браузером пользователя и веб-сервером, обеспечивая конфиденциальность и целостность данных. Это особенно важно при передаче личных данных, таких как пароли, номера кредитных карт и другой чувствительной информации.

Для получения этого сертификата можно воспользоваться утилитой Let’s Encrypt.

**Let's Encrypt** — это открытая сертификационная служба, предоставляющая бесплатные SSL-сертификаты. Она была создана с целью обеспечения доступности и простоты получения и установки SSL-сертификатов для всех веб-сайтов. Let's Encrypt автоматизирует процесс генерации, подписания и обновления сертификатов.

## Чекпоинты

### Подготовка
1. Создайте одну виртуальную машину (ВМ) с Ubuntu Server в VirtualBox.
2. Настройте сеть. В настройках ВМ выберите тип подключения "Сетевой мост" (Bridged Adapter).
3. Запустите ВМ и подключитесь к ней по SSH.

### Задания

#### Установка сервера и создание главной страницы
1. Установите Nginx.
2. Узнайте IP-адрес вашей ВМ.
3. Найдите и запишите IP-адрес (например, `192.168.1.55`).
4. Создайте главную HTML-страницу, вписав в неё этот IP:
```bash
echo "My private IP is $(hostname -I)" | sudo tee /var/www/html/index.html
```
5. Перезагрузите Nginx.

#### Настройка локального DNS (файл hosts)
Так как у нас нет публичного домена, мы "обманем" ваш основной компьютер, чтобы он знал, куда обращаться.
1. На вашем основном компьютере (не на ВМ) откройте для редактирования файл `hosts`:
   * **Linux/macOS:** `sudo vim /etc/hosts`
   * **Windows:** Откройте Блокнот от имени Администратора и откройте файл `C:\Windows\System32\drivers\etc\hosts`
2. Добавьте в конец файла новую строку, связав IP-адрес вашей ВМ с выдуманным доменом:
```text
<IP_АДРЕС_ВАШЕЙ_ВМ> my-secure-server.local
```
3. Теперь при вводе `my-secure-server.local` в браузере ваш компьютер будет обращаться напрямую к вашей ВМ.

#### Создание самоподписанного SSL-сертификата
1. В терминале вашей виртуальной машины создайте директории для сертификата:
```bash
sudo mkdir -p /etc/ssl/private
sudo chmod 700 /etc/ssl/private
```
2. Сгенерируйте ключ и сертификат одной командой с помощью OpenSSL:
```bash
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /etc/ssl/private/nginx-selfsigned.key -out /etc/ssl/certs/nginx-selfsigned.crt
```
3. Программа задаст вам несколько вопросов. Большинство можно оставить по умолчанию, но обязательно заполните поле `Common Name (e.g. server FQDN or YOUR name)`. Введите сюда домен, который вы придумали на шаге 1: `my-secure-server.local`.

#### Настройка Nginx для работы с HTTPS
1. Создайте новый файл конфигурации для вашего сайта на ВМ:
```bash
sudo nano /etc/nginx/sites-available/my-secure-server
```
