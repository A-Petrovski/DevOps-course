# Module description

В первой главе мы обучаемся работе с встроенными утилитами Linux систем. Для этого можно использовать виртуальные машины. Использование виртуальных машин очень удобно, потому что они позволяют развернуть несколько операционных систем на одном физическом компьютере. Это может быть полезно, например, для тестирования приложений на разных операционных системах, для разработки приложений, которые должны работать на разных платформах, или просто для того, чтобы изолировать разные операционные системы друг от друга.

## Почему Linux?

1. **Настраиваемость.** Linux является операционной системой с открытым исходным кодом, что позволяет пользователям иметь полный доступ к исходному коду и модифицировать его под свои нужды. Это позволяет DevOps-инженерам настраивать систему под свои конкретные требования и рабочие процессы.
2. **Совместимость.** Linux совместима с широким спектром оборудования, включая старые системы и устройства с низкой мощностью. Это делает ее хорошим выбором для DevOps-инженеров, работающих над проектами, которые должны поддерживать различные конфигурации оборудования.
3. **Безопасность.** Linux, как правило, считается более безопасной, чем Windows, благодаря своей архитектуре.
4. **Производительность.** Linux славится своей эффективностью и быстрой производительностью, что может быть важно для DevOps-инженеров, работающих над ресурсоемкими проектами или большими наборами данных.
5. **Поддержка сообщества (Open Source).** Linux имеет большое и активное сообщество пользователей и разработчиков, что обеспечивает доступ к множеству онлайн-ресурсов, документации и поддержке. Это особенно полезно для начинающих DevOps-инженеров или тех, кто ищет ответы на вопросы по использованию Linux в своих проектах.

Хотелось бы уточнить, что использование Ubuntu было бы предпочтительнее, так как большинство современных решений базируется на Ubuntu/CentOS, но CentOS является проприетарной системой. Также большим плюсом является акцент на работе с CLI без GUI, следовательно командная строка - твой лучший друг, никаких интерфейсов, так как в реалиях работы с серверами библиотеки, которые предоставляют GUI, обычно не включены в образы, дабы уменьшить вес исходного сервера, следовательно, у тебя есть только командная строка.

Для получения дополнительных теоретических знаний можешь использовать “Полезные ссылки”, а также дополнительный ресерч в интернете.

## Введение
Linux — это свободная и открытая операционная система, которая используется на серверах, компьютерах, смартфонах и множестве других устройств. В отличие от Windows и macOS, Linux является бесплатной, а ее исходный код доступен для изучения и модификации. Одним из самых популярных дистрибутивов Linux является Ubuntu. Это удобная и интуитивно понятная система, идеально подходящая для новичков. Ubuntu desktop поставляется с графическим интерфейсом, множеством приложений и удобной поддержкой сообщества. Также существует Ubuntu Server, созданный для работы на серверах без GUI. Для работы с линукс мы будем использовать VirtualBox.

VirtualBox — это специальное средство для виртуализации, позволяющее запускать операционную систему внутри другой. С помощью VirtualBox мы можем не только запускать ОС, но и настраивать сеть, обмениваться файлами и делать многое другое. Виртуальная машина (созданная с помощью VirtualBox) не полностью изолирована, но она предоставляет высокий уровень изоляции от основной системы, что делает её удобной песочницей для обучения. Для того чтобы поднять виртуальную машину нам необходим ISO образ операционной системы.

ISO-образ — это файл, содержащий точную копию содержимого оптического диска, такого как CD или DVD. Обычно его используют для хранения операционных систем, программного обеспечения или данных в формате, который легко записать на диск или использовать напрямую. ISO-файл можно сравнить с "виртуальным диском", он содержит всё, что было бы на физическом диске, включая файловую структуру, загрузочные сектора и т.д.

Как уже было сказано в вводном разделе, для работы ты часто будешь использовать командную строку (Command Line Interface, CLI).

**Командная строка** — это способ взаимодействия пользователя с Shell через текстовый интерфейс. Она позволяет пользователю вводить команды и получать текстовый вывод. Именно она появляется при открытии терминала.

**Shell (оболочка)** — это интерфейс между пользователем и операционной системой, который позволяет вводить команды, обрабатывать их и взаимодействовать с ядром системы. В русскоязычной литературе Shell принято называть интерпретатором командной строки. Самым популярным Shell в Linux является bash. С ним в этом разделе тебе и придется работать. Таска предназначена дать тебе базовое представление о командах в Linux и ознакомить с их работой.

## Чекпоинты
1. Создать виртуальную машину Ubuntu на VirtualBox, используя официальный ISO образ.
2. Прочти/узнай отличия абсолютного пути от относительного, это важно. Посмотри абсолютный путь папки в которой ты находишься. Сделай полный вывод её содержимого, включая скрытые файлы.
3. Перейди на одну директорию ниже, вернись обратно.
4. Перейди в root директорию, сделай полный вывод содержимого (`ls -l`). После чего сделай полный вывод, включая скрытые файлы (`ls -la`). Разберись что означает каждая колонка в выводе.
5. Перейди в свою домашнюю директорию. Создай файл “dog.txt”. С помощью команды “echo” запиши в файл название своего любимого фильма.
6. При помощи графического редактора vim добавь имена 4х главных героев в файл с новой строки.
7. Выведи содержимое файла с помощью команды “cat”.
8. Переименуй файл с “dog.txt” в “cat.txt”. Создай новую директорию под названием “animals”, перемести “cat.txt” в неё.
9. Находясь в директории “animals” выведи содержимое файла “cat.txt” используя относительный путь к файлу (также такое обращение к файлу называют “через точку”). Перейди в root директорию. Выведи содержимое файла “cat.txt” с помощью абсолютного и относительного путей.
10. Создай еще несколько файлов с названиями животных в директории “animals”. Например “mouse.txt” и др.
11. Введи название своего любимого мультика в “mouse.txt” с помощю “>”. Разберись в чем разница между “>” и “>>”.
12. Найди в директории “animals” файл “cat.txt” с использованием команды “grep”. Далее сделай то же самое с помощью команды “find.”
13. Удали один из файлов в директории “animals”. После чего удали директорию “animals”. Прочитай про варианты флагов у команды “rm”.
14. Выведи историю своего взаимодействия с командной строкой и найди команду которую ты вводил для создания директории. (Используй pipe “|”)
15. Используемые команды должны быть записаны в отдельный файлик.
