# Вопросы для самоконтроля

## 1. Виртуализация (VirtualBox / VMware / Cloud)
- **Принцип:** Гипервизор делит ресурсы физического сервера (CPU, RAM, диск, сеть) между изолированными ВМ.
- **VirtualBox / VMware Workstation:** Гипервизоры 2-го типа поверх основной ОС для локальной разработки и тестов.
- **VMware ESXi и Cloud (AWS, GCP):** Промышленные решения и облачные платформы с оплатой по потреблению, быстрым масштабированием и отказоустойчивостью.

## 2. Пользователи, группы и базовые команды Linux
- **Роль:** Разграничение доступа к файлам и процессам по владельцу (`UID`) и группе (`GID`).
- **Команды и флаги:**
  - `useradd` — создание пользователя. Флаги: `-m` (создать домашнюю папку), `-s` (задать оболочку). *Пример:* `sudo useradd -m -s /bin/bash raymond`.
  - `usermod` — изменение пользователя. Флаги: `-aG` (добавить в доп. группу), `-s` (сменить оболочку). *Пример:* `sudo usermod -aG sudo raymond`.
  - `groupadd` — создание группы. *Пример:* `sudo groupadd devops`.

## 3. Аутентификация и SSH (`sshd_config`)
- **SSH:** Протокол шифрованного удалённого управления сервером.
- **Методы входа:** По паролю (сверка хеша в `/etc/shadow`) и по паре ключей (публичный на сервере в `authorized_keys`, приватный у клиента).
- **Настройки `/etc/ssh/sshd_config`:**
  - `Match User <имя>` — применение правил к конкретному пользователю.
  - `PubkeyAuthentication yes/no` — разрешение/запрет входа по ключу.
  - `PasswordAuthentication yes/no` — разрешение/запрет входа по паролю.

## 4. Управление правами (`chmod`)
- **Права и категории:** Владелец (`u`), группа (`g`), остальные (`o`). Права: `r` (`4` — чтение), `w` (`2` — запись), `x` (`1` — выполнение/вход в папку).
- **Численная нотация:** Сумма прав для каждой категории. *Пример:* `chmod 754 file` (`7`=`rwx`, `5`=`r-x`, `4`=`r--`).
- **Символьная нотация:** Точечное изменение через `+`, `-`, `=`. *Пример:* `chmod u=rwx,g=rx,o=r file` или `chmod g+x script.sh`.

## 5. Принципы настройки доступов
- **Минимальные привилегии:** Пользователь получает только нужные для работы права.
- **Разделение:** Админам — ключи и `sudo`, обычным пользователям — изоляция в своих папках. Проверка конфигов перед перезапуском (`sshd -t`, `visudo -c`).

## 6. Настройка `Raymond` и `John`
- `Raymond`: вход по ключу (`PubkeyAuthentication yes`, `PasswordAuthentication no`), беспарольный `sudo` через `/etc/sudoers.d/raymond`.
- `John`: вход строго по паролю (`PasswordAuthentication yes`, `PubkeyAuthentication no`), без доступа к `sudo`.

## 7. Права на файлы (чтение без редактирования)
- Для чтения файла в чужой директории нужны права `x` на папку и `r` на файл.
- **Классический способ:** `chmod 755 /home/raymond` и `chmod 644 /home/raymond/file`.
- **Точечный способ (ACL):** `setfacl -m u:john:x /home/raymond` и `setfacl -m u:john:r /home/raymond/file` (флаг `-m` изменяет правила ACL).

## 8. Создание и запуск shell-скрипта
- Первая строка файла — шебанг (`#!/bin/bash`), указывающий интерпретатор.
- Для запуска скрипта другим пользователем нужны права **и на чтение (`r`), и на выполнение (`x`)**, так как интерпретатор читает код файла. *Пример:* `chmod 750 script.sh` или `setfacl -m u:raymond:rx script.sh`.

## 9. Изменение интерпретатора (`usermod`)
- Команда `sudo usermod -s /bin/bash john` (флаг `-s` задаёт оболочку) перезаписывает 7-е поле в `/etc/passwd`. Изменения вступают в силу при следующем входе в систему.

## 10. Интерпретаторы (`bash`, `sh`)
- **Shell:** Программа-посредник между пользователем и ядром ОС.
- **`sh`:** Минималистичная оболочка стандарта POSIX без истории и автодополнения. Используется для быстрого запуска системных скриптов.
- **`bash`:** Расширенная оболочка по умолчанию для пользователей. Поддерживает автодополнение (`Tab`), историю команд, массивы и сложные сценарии.
