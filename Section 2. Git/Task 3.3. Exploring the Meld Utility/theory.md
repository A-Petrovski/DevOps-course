## 3.3.1 Цель задания
Освоить **Meld** как инструмент визуального сравнения и слияния файлов и каталогов, который используется:
* при работе с Git;
* при разборе конфликтов;
* при анализе различий между версиями кода и конфигураций.

## 3.3.2 Описание задания
В рамках этого задания необходимо установить и изучить утилиту Meld, а затем выполнить серию практических упражнений по работе с:
* diff файлов;
* diff директорий;
* разрешением merge-конфликтов;
* интеграцией с Git.

## 3.3.3 Установка и базовая настройка
**Задание:**
1. Установите Meld:
   * **Linux:** `sudo apt install meld` / `sudo dnf install meld`
   * **macOS:** `brew install --cask meld`
   * **Windows:** скачать с официального сайта.
2. Убедитесь, что Meld запускается:
   * из графического интерфейса;
   * из терминала командой: `meld`

**Чекпоинты:**
Вы должны уметь:
* запустить Meld;
* объяснить, в каких сценариях он удобнее встроенных diff-инструментов IDE.

## 3.3.4 Сравнение файлов
**Задание:**
1. Создайте два файла:
   * `version_a.txt`
   * `version_b.txt`
2. Добавьте в них отличающиеся строки. Откройте файлы в Meld: `meld version_a.txt version_b.txt`
3. Изучите:
   * подсветку различий;
   * навигацию по изменениям;
   * копирование изменений между версиями.

**Чекпоинты:**
Вы умеете:
* находить различия;
* переносить изменения;
* объяснять назначение элементов интерфейса.

## 3.3.5 Сравнение директорий
**Задание:**
Создайте копию проекта: `cp -r project project_copy`
1. Измените несколько файлов в `project_copy`. Запустите: `meld project project_copy`
2. Проанализируйте:
   * отличающиеся файлы;
   * отсутствующие элементы;
   * полностью совпадающие объекты.

**Чекпоинты:**
Вы умеете:
* сравнивать структуру каталогов;
* выявлять расхождения в конфигурациях и коде.

## 3.3.6 Разрешение merge-конфликтов
**Задание:**
1. В Git-репозитории создайте конфликт:
   * измените один и тот же файл в двух ветках;
   * выполните merge.
   После появления конфликта откройте файл через Meld: `meld file_with_conflict` или используйте: `git mergetool`
2. Разрешите конфликт в режиме 3-way merge.

**Чекпоинты:**
Вы умеете:
* читать conflict-markers;
* работать с трёхсторонним merge;
* сохранять корректную итоговую версию.

## 3.3.7 Интеграция Meld с Git
*(опционально, почти никогда не используется)*

**Задание:**
Настройте Meld как diff- и merge-tool:
```bash
git config --global diff.tool meld
git config --global merge.tool meld
```
1. Проверьте работу:
```bash
git difftool
git mergetool
```

**Чекпоинты:**
Вы понимаете:
* как Git использует внешние инструменты;
* когда Meld предпочтительнее встроенных средств IDE.

## 3.3.8 Практический сценарий
**Задание:**
Смоделируйте реальную рабочую ситуацию:
1. Есть две версии конфигурации:
   * `config_old/`
   * `config_new/`
2. Необходимо:
   * найти все отличия;
   * перенести только нужные изменения;
   * зафиксировать, какие файлы были изменены.
Используйте Meld как основной инструмент анализа.

**Чекпоинты:**
Вы можете:
* применять Meld в практических задачах;
* работать с конфигурациями и кодом без риска потери данных.

## 3.3.9 Итоговые критерии выполнения
Студент считается освоившим задание, если он может:
* сравнить файлы и директории в Meld;
* разрешить merge-конфликт через Meld;
* объяснить разницу между:
  * diff-tool и merge-tool;
* настроить Meld для работы с Git;
* обосновать, когда Meld удобнее, чем:
  * встроенные инструменты IDE;
  * консольные утилиты (diff, vimdiff).
