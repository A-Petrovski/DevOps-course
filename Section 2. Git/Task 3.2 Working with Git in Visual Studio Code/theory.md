## Task 3.2. Работа с Git в Visual Studio Code

Я не использую Visual Studio Code как основной инструмент и в повседневной работе предпочитаю PyCharm. Тем не менее, ваша задача — самостоятельно разобраться, как выполняются основные операции с Git в этом редакторе, и найти аналоги привычных действий, которые вы уже знаете по работе в PyCharm. Большинство современных редакторов с поддержкой AI-инструментов основаны на Visual Studio Code, поэтому владение этим инструментом сегодня является не просто преимуществом, а необходимым навыком.
