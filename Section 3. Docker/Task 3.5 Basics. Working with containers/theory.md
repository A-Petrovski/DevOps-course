## Введение

В предшествующих заданиях мы узнали несколько команд, которые управляют жизнью контейнеров (`run`, `ps`, `rm`), и узнали, что можно удалить контейнер без остановки при помощи команды `rm --force`. Но для того, чтобы не использовать `rm --force`, необходимо прежде всего остановить контейнер, а для этого есть команда `stop`.

## Остановка контейнера: `docker stop`

`docker stop` — это команда, которая используется для остановки.

* Действие команды `stop` похоже на отправку сигнала `SIGTERM` процессу, то есть она мягко останавливает процесс.
* Если в ходе остановки контейнера процесс не реагирует на сигнал `SIGTERM`, то через 10 секунд Docker отправляет уже безапелляционный сигнал — `SIGKILL`, который сразу завершает процесс.
* После этого остановленный контейнер можно удалить без команды `--force`.

## Список всех контейнеров: флаг `-a`

Для того, чтобы показать список всех контейнеров, включая остановленные, у команды `ps` есть флаг `-a`, который используется для отображения всех контейнеров.

## Запуск остановленного контейнера: `docker start`

Вернуть к жизни контейнер можно через команду `docker start` — она используется для старта остановленного контейнера.

* Важно различать команды `run` и `start` — первая используется для запуска нового контейнера, а вторая — для запуска существующего остановленного контейнера.

## Массовое удаление контейнеров: `docker rm $(docker ps -aq)`

Полезная команда для работы с группами контейнеров:

```bash
docker rm $(docker ps -aq)
```

В данной команде производится два вызова команды `docker`, и вывод одной команды используется как аргумент для другой:

* **`docker ps -aq`** — что делает команда `ps -a`, мы выяснили выше. Флаг `-q` указывает на то, что нужно вывести не всю информацию по контейнерам, а лишь их идентификаторы. Идентификаторы контейнеров без флага указываются в первом столбце. Этот флаг применяется для команд, в которых список контейнеров используется далее для других команд, в том числе не связанных с Docker.
* **`docker rm`** — удаление контейнеров. Без дополнительных флагов команда `rm` не позволяет удалять работающие контейнеры, поэтому только остановленные контейнеры будут удалены.
* Для тотальной чистки можно добавить флаг `--force`, который удалит и работающие контейнеры тоже.
* Такого же результата можно добиться при помощи команды `docker container prune`, следует учесть только, что она не дает возможности так же гибко работать с контейнерами при помощи командной строки.
