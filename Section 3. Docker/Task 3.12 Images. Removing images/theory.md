## Введение

В этом задании мы познакомимся с командами для чистки системы от образов. Docker не стремится удалять образы и контейнеры после себя, даже если они уже не используются. Это касается и контейнеров, и образов. Часто это приводит к тому, что система через какое-либо время засоряется — особенно, если работы на хосте производятся без вмешательства человека, в случае автоматической сборки образов, к примеру. Поэтому так существенно уметь чистить хвосты. Нужно обратить внимание, что бОльшая часть команд очень напоминает список команд для чистки контейнеров.

## Команда docker rmi

`docker rmi` — команда удаляет один или несколько образов. Можно передавать как полные имена образов — например, `nginx:stable`, так и их id — `0dac5b41d811`.

Существует особенность удаления — не всегда происходит именно удаление. В вводном задании про образы мы говорили про команду `tag`, которая позволяет назначить тег на существующий образ, при котором два тега указывают на один образ. Так вот, в таком случае удаление образа происходит только в тот момент, когда на него не указывает ни один тег. Эта схема похожа на то, как происходит удаление файла при наличии жесткой ссылки в файловой системе.

Обращаем ваше внимание на то, что, по аналогии с рабочими контейнерами, удаление образов, используемых в каких-либо контейнерах, невозможно, исключение составляет флаг `--force`, который удалит образ принудительно.

Кроме того, нужно помнить, что схема с удалением контейнеров, с которой мы познакомились ранее, работает и здесь, поэтому команда:

```bash
docker rmi $(docker images -aq)
```

также будет работать.

## Команда docker system prune и её аналоги

`docker system prune` — команда позволяет удалить в системе все неиспользуемые объекты: контейнеры, образы, Volumes и прочие сущности. Задача этой команды простая — ее запуск позволяет удалить все, что не используется на данный момент. Для удаления Volumes требуется добавить флаг `--volumes`, но помните, что удаление Volumes в автоматическом режиме — не всегда хорошая идея.

Есть также отдельные команды для чистки только образов, контейнеров, томов или сетей, это:
- `docker image prune`
- `docker container prune`
- `docker volume prune`
- `docker network prune`
